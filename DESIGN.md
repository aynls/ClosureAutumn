# ClosureAutumn palette

The palette is adapted from the local Closure-Autumn Cursor theme as of
2026-10-14. UI roles are mapped to the closest JetBrains equivalents.
Translucent editor highlights are composited over the editor background
for color-scheme entries that use opaque RGB colors.

| Role | Color |
| --- | --- |
| Editor and sidebar | `#23211F` |
| Popup | `#2C2A27` |
| Input | `#302E2A` |
| Hover | `#34312D` |
| List selection | `#3B3732` |
| Border | `#45413C` |
| Primary text | `#F5F1EA` |
| Secondary text | `#B8B1A7` |
| Disabled text | `#756D63` |
| Focus accent | `#DDA080` |
| Keywords and decorators | `#F39A7E` |
| Types and namespaces | `#EDD799` |
| Functions and methods | `#91D6BF` |
| Strings and regular expressions | `#BDD999` |
| Numbers, constants, and escapes | `#EDAAB8` |
| Variables and parameters | `#F5F1EA` |
| Fields and events | `#E8C3AC` |
| Comments | `#B3AAA1` |
| Operators | `#D2BAA1` |
| Punctuation | `#BFB3A5` |

Syntax uses regular weight and non-italic comments. Markdown headings remain
bold. Language-specific keys inherit shared semantic roles. Host language
services can classify tokens differently from Cursor, so identical colors
do not guarantee identical highlighting of every token.
